1. Install VirtualBox

Download VirtualBox for Windows from https://www.virtualbox.org/ and run the installer. No reboot required for the host-only network on Windows 10/11.

2. Provision the Kali VM
# Option A — already have the .ova:
pwsh scripts\setup_kali_vm.ps1 -OvaPath C:\iso\kali.ova

# Option B — fetch it once (online, ~3GB):
pwsh scripts\setup_kali_vm.ps1 -Download

The script imports the appliance, attaches a host-only adapter, mounts bundles\labs as a shared folder, snapshots a clean state, and prints SSH/RDP connection details.

3. Fetch challenge artifacts

The bundled labs live under bundles\labs\ and are accessed directly from the VM via the shared folder. They are mounted at /media/sf_skillSprint-labs inside the guest.

4. Work a lab
  1. Go to /labs and open any self_hosted_offline lab.
  2. Click "Open challenge files" to download the artifact, OR access it from /media/sf_skillSprint-labs/<...> inside the VM.
  3. Perform the analysis / solve the challenge.
  4. Submit the flag (or write-up URL) on the lab page to claim XP — all flag-hash comparison happens locally.
5. Resetting the VM
VBoxManage snapshot "SkillSprint-Kali" restore skillSprint-clean-state
