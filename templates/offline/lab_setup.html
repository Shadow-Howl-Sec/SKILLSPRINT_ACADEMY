Kali VM Quick Start (for bundled self_hosted_offline labs)
1. Install VirtualBox

Download from virtualbox.org. No reboot needed for host-only adapter on Windows 10/11.

2. Provision Kali VM
# Option A — import existing .ova:
pwsh scripts\setup_kali_vm.ps1 -OvaPath C:\iso\kali.ova

# Option B — download (~3GB):
pwsh scripts\setup_kali_vm.ps1 -Download

Script imports appliance, adds host-only adapter, mounts bundles\labs as shared folder, snapshots clean state.

3. Access Bundled Labs

Labs under bundles\labs\ mount at /media/sf_skillsprint-labs inside Kali.

  1. Go to /labs → open a self_hosted_offline lab
  2. Click "Open challenge files" or access from Kali at /media/sf_skillsprint-labs/...
  3. Analyze / solve the challenge
  4. Submit flag/write-up for XP
4. Reset VM to Clean State
VBoxManage snapshot "Skillsprint-Kali" restore skillsprint-clean-state
Target VM Setup References
Metasploitable2

Download from SourceForge/Rapid7. Import .ova, attach to same host-only network as Kali. Default creds: msfadmin/msfadmin

DVWA / Juice Shop

Docker: docker run -d -p 80:80 vulnerables/web-dvwa or docker run -d -p 3000:3000 bkimminich/juice-shop. Attach to host-only network.

GOAD (Game of AD)

GitHub: Orange-Cyberdefense/GOAD. Deploy via Vagrant/VirtualBox. Creates DC01 + WIN10 joined to GOAD.LOCAL. Creds in repo docs.

Wazuh Manager

Deploy via docker-compose from Wazuh docs. Enroll agents on Metasploitable2, GOAD-DC01, GOAD-WIN10. Configure Sysmon on Windows.

Network Config

All VMs on same host-only network (e.g., 192.168.56.0/24). Kali needs promiscuous mode: VM Settings → Network → Adapter 2 → Promiscuous Mode: Allow All.
