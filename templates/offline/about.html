SkillSprint Academy is configured to run entirely locally on your machine — no cloud services, no telemetry, no payment gateway, no external AI API calls.

What's enabled locally
  • Full curriculum (Tier 0 → Tier 4) seeded into a local SQLite database.
  • Bundled challenge artifacts under bundles/labs/ — lab flag hashing works fully offline.
  • AI tutor routes to a local Ollama instance when running; otherwise deterministic topic-specific hints.
  • Interactive in-browser exercises (Python via Pyodide, regex / cipher / quiz widgets) — vendored under static/vendor/.
  • Contact form messages are stored in a local inbox instead of being emailed.
What's disabled in offline mode
  • Razorpay payments — /create_order returns 404.
  • Google OAuth login — the route is not registered.
  • Community / leaderboard sharing — out of scope offline.
  • Email verification — emails are auto-verified on registration.
  • Password-reset email flow — use python manage.py reset-password instead.
Setup guides
  • Lab setup guide — provision a local Kali VirtualBox VM.
  • AI tutor setup — install / pick an Ollama model.
  • External resource cache — one-time online sync of public CS articles.

Status indicator — {% if offline %}offline{% else %}online{% endif %}. Set OFFLINE_MODE=true in .env to force offline behaviour.
